# Приложение для распознавания цифр

## Обзор

Данное приложение выполняет распознавание цифр, нарисованных пользователем, с использованием нейронной сети, обученной на наборе данных MNIST. Оно предоставляет графический интерфейс (GUI) для рисования цифр и предсказания модели.

## Возможности

### 1. **Обучение модели**
   - Используется набор данных MNIST, содержащий изображения рукописных цифр размером 28x28 пикселей.
   - Нормализация данных и обучение модели с использованием фреймворка Keras.
   - Архитектура модели включает:
     - Слой Flatten для преобразования входных данных.
     - Полносвязный слой Dense (128 нейронов, ReLU).
     - Выходной слой Dense (10 нейронов, softmax).

### 2. **Графический интерфейс (GUI)**
   - Холст 280x280 пикселей с сеткой 28x28 для рисования цифр.
   - Кнопка "Определить" для предсказания нарисованной цифры.
   - Кнопка "Стереть" для очистки холста.

### 3. **Распознавание цифр**
   - Обработка нарисованного изображения, включая инвертирование и нормализацию данных.
   - Использование обученной модели для предсказания.
   - Визуализация предсказанной цифры и нарисованного изображения.

## Установка и запуск

1. Убедитесь, что Python 3.8+ установлен.

2. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

3. Сохраните код в файл `main.py` и запустите его:
   ```bash
   python main.py
   ```

4. Откроется окно приложения с холстом для рисования цифр.

## Использование

1. Нарисуйте цифру на холсте, удерживая левую кнопку мыши.
2. Нажмите кнопку "Определить" для предсказания.
3. Результат будет выведен в консоли и отобразится нарисованное изображение.
4. Для очистки холста нажмите "Стереть".

## Требования

- Python 3.8+
- TensorFlow/Keras
- Tkinter (входит в стандартную библиотеку Python)
- Pillow

## Ограничения

- Приложение распознаёт только отдельные цифры, нарисованные вручную.
- Холст ограничен сеткой 28x28 для соответствия входным данным модели.

## Развитие

- Возможна интеграция с более сложными архитектурами моделей.
- Добавление визуализации вероятностей предсказания для каждой цифры.
- Расширение на распознавание символов или слов.
